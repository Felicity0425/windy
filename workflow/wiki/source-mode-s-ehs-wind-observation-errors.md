# Estimates of Mode-S EHS aircraft-derived wind observation errors using triple collocation

## 来源信息

- **本地原文**：[原始文稿](../raw/基于三重协同法的Mode-S EHS飞机风观测误差估计/amt-9-4141-2016.md)
- **发表位置**：Atmospheric Measurement Techniques 9, 4141–4150
- **核心对象**：Mode-S EHS 飞机风观测误差估计

## 核心观点

- 要想把飞机监视数据用于气象业务，首先必须知道其误差特性，因此作者采用 triple collocation 方法评估 [[mode-s-ehs|Mode-S EHS]] 风观测误差。
- 该方法联合了两类独立观测和数值模式输出，避免简单对模式“对真值”的假设。
- 论文的意义不在于提供新模型，而在于为 [[aircraft-derived-meteorological-observations|Aircraft-derived meteorological observations]] 的可用性建立定量依据。

## 关键结果

- 文中估计的 Mode-S EHS 风观测误差在近地面小于 1.4 ± 0.1 m/s。
- 在 500 hPa 附近约为 1.1 ± 0.3 m/s。
- 这说明飞机衍生风观测具有可观的应用潜力，但必须经过质量控制与误差建模。

## 注意事项

- 论文重点在误差评估，不直接提供业务处理流水线。
- 其结果为后续更大规模的业务系统（如 [[emaddc|EMADDC]]）提供了可信性前提。
