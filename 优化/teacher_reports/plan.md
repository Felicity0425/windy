老师的回复其实把核心问题确认了：**这一批 AMDAR 点只有“累计下发时间”，没有逐点原始观测时间**。所以你现在做的不是“找回真实时间”，而是利用 ADS-B 航迹进行**观测时间重建/估计**。

这个方法能做，但你当前的结果还不能直接进入风场重构。关键不是覆盖率，而是匹配精度：

* 行级覆盖率 98.7%：只能说明算法几乎总能找到一个候选点；
* 水平距离中位数 24.98 km：说明至少一半观测匹配偏差超过约 25 km；
* 90 分位 46.58 km：很可能匹配到了错误航段、错误方向或错误班次；
* 航向差中位数 62.76°：如果比较的确实是飞机航向，说明轨迹几何一致性很差。

## 先检查一个非常关键的问题

你最开始的 AMDAR 表里是：

```text
静温、风向、风速
```

这里的“风向”是**气象风向**，不是飞机的飞行航向。

因此，脚本里的“航向差”必须确认：

* ADS-B 航向：飞机运动方向；
* AMDAR 风向：风从哪个方向吹来；
* 这两者不能比较。

如果脚本把 AMDAR 的“风向”和 ADS-B 的“航向角”做差，那么当前的 `62.76°` 没有匹配意义，应立即从代价函数和质量评价中移除。

AMDAR 的飞机运动方向应通过相邻 AMDAR 点计算：

[
\text{track bearing}_i
======================

\operatorname{bearing}
\left(
P_{i-1},P_{i+1}
\right)
]

前提是已经基本确定这些点的先后顺序。若原表行顺序不可靠，就不能直接计算。

---

# 当前原型为什么会“覆盖率高、距离却很大”

很可能是算法做到了：

> 给每个 AMDAR 点强行找到一个满足单调条件的 ADS-B 点。

但没有充分回答：

> 这是不是同一天、同一飞机、同一个航段、同一个飞行方向的轨迹？

也就是说，目前优化目标可能偏向“必须匹配”，而不是“匹配不好就拒绝”。

对于风场重构，**宁可只保留 50% 的高质量点，也不要保留 98% 的可疑点**。错误时间和错误位置会把风场结构抹平，甚至制造假风切变。

---

# 建议把匹配流程改成四层

## 第一层：先筛选正确的 ADS-B 航段

不要一上来就逐点找最近位置。应先为每个 AMDAR 批次筛选候选航段。

建议候选航段必须满足：

1. 航班号一致；
2. 日期在合理范围内；
3. 整个 AMDAR 点集的空间包络与 ADS-B 航迹有较大重叠；
4. 高度范围一致；
5. 飞行阶段一致；
6. ADS-B 航迹能够覆盖大部分 AMDAR 点，而不是只有一个点碰巧靠近。

AMDAR 批次时间虽然不是真实观测时间，但仍可以作为宽松条件。例如：

* 爬升或下降批次：前后放宽 1～2 小时；
* 巡航累计下发批次：可放宽 3～6 小时；
* 如果时区和日期也有疑问，可扩大到前后 12 小时，但要加强空间约束。

同一个航班号可能每天重复，也可能更换飞机，因此要按：

```text
航班号 + 日期 + 机尾号 + 连续航段
```

来构造候选轨迹。

如果 AMDAR 没有机尾号，机尾号只能用于区分 ADS-B 候选航段，不能作为硬匹配条件。

---

## 第二层：先匹配整条轨迹，再匹配单个点

不要让每个 AMDAR 点独立寻找最近的 ADS-B 点。应把同一个批次看成一条点序列，用动态规划、Viterbi 或单调 DTW 做整体匹配。

目标函数可写成：

[
J =
\sum_i
\left[
w_h C_{h,i}
+
w_z C_{z,i}
+
w_d C_{d,i}
+
w_p C_{p,i}
\right]
+
w_r C_{\mathrm{reverse}}
+
w_j C_{\mathrm{jump}}
]

其中：

* (C_h)：水平距离；
* (C_z)：高度差；
* (C_d)：AMDAR 点列方向与 ADS-B 轨迹方向之差；
* (C_p)：上升、巡航、下降阶段是否一致；
* (C_{\mathrm{reverse}})：是否沿 ADS-B 时间轴倒退；
* (C_{\mathrm{jump}})：相邻匹配点是否发生不合理的时间或距离跳跃。

必须满足：

[
t_{i+1}^{ADS-B} \ge t_i^{ADS-B}
]

同时尽量保证沿航迹距离也是单调增加的。

---

## 第三层：按照飞行阶段分别排序和约束

老师已经说明数据是按飞行阶段累计下发的，所以爬升、巡航、下降不要用完全相同的规则。

### 爬升阶段

主要约束：

* 时间增加；
* 高度整体增加；
* AMDAR 位置沿 ADS-B 航迹向前移动；
* 不允许频繁高度反转。

可以允许小幅高度波动，但总体趋势必须为上升。

### 下降阶段

主要约束：

* 时间增加；
* 高度整体降低；
* 空间轨迹逐渐接近目的地；
* 不应匹配到同一航班之前的巡航段。

### 巡航阶段

高度约束相对弱，应更加依赖：

* 整条路线形状；
* 点序列方向；
* 沿轨距离；
* ADS-B 航段的起点和终点；
* 相邻 AMDAR 点与 ADS-B 点之间的距离变化。

如果同一个“相同时间组”中同时包含明显不同的高度趋势，建议先按飞行阶段、高度层和空间连续性再次分组，而不是整组一起匹配。

---

# 推荐使用“投影到 ADS-B 轨迹”，而不是只找最近 ADS-B 点

ADS-B 数据可能每隔几十秒或一分钟才有一条。AMDAR 点的实际位置通常落在两个 ADS-B 点之间。

对于 AMDAR 点 (P)，先找到相邻 ADS-B 轨迹段：

[
A(t_0)\rightarrow B(t_1)
]

把 (P) 投影到线段 (AB)，得到比例 (\lambda)：

[
0\leq\lambda\leq1
]

重建时间为：

[
t_{\mathrm{reconstructed}}
==========================

t_0+\lambda(t_1-t_0)
]

这样比直接赋予最近 ADS-B 点的时间更平滑，也能避免大量 AMDAR 点获得完全相同的 ADS-B 时间。

但只允许在线段内部插值。若需要在线段两端之外外推，应严格限制，例如最多外推 60～120 秒，超过就拒绝。

---

# 给匹配结果设置质量等级

下面是一套可以作为初始版本的工程阈值，后续应根据你的风场网格分辨率调整。

## A级：可用于较精细的四维风场

建议同时满足：

```text
水平距离 ≤ 3 km
垂直距离 ≤ 300 m
轨迹方向差 ≤ 20°
ADS-B相邻采样间隔 ≤ 60 s
无候选航段歧义
估计时间不确定度 ≤ 60 s
```

## B级：可以使用，但应降低权重

```text
水平距离 ≤ 8 km
垂直距离 ≤ 600 m
轨迹方向差 ≤ 35°
ADS-B采样间隔 ≤ 120 s
估计时间不确定度 ≤ 180 s
```

## C级：只能用于粗时间窗或超级观测

```text
水平距离 ≤ 15 km
垂直距离 ≤ 1000 m
轨迹方向差 ≤ 60°
估计时间不确定度 ≤ 600 s
```

这类点不建议直接进入分钟级、高分辨率风场，可以放进 30 分钟或 1 小时时间窗。

## 拒绝

出现以下任一情况建议拒绝：

* 水平距离超过 15～20 km；
* 飞行阶段不一致；
* 匹配时间倒退；
* 同时存在两个质量相近但时间相差很大的候选航段；
* 需要长时间外推；
* ADS-B 轨迹无法覆盖 AMDAR 点集；
* 匹配后的飞机速度明显不合理。

一个更通用的规则是：

> 匹配水平残差最好小于风场网格间距的一半。

例如你的风场网格是 10 km，那么 25 km 的中位距离绝对不能接受；即使网格是 50 km，25 km 也只能算边缘可用，不能用于精细结构。

# 时间不确定度不能只给固定值

建议每条数据根据实际匹配情况计算：

[
\sigma_t^2 =
\sigma_{\mathrm{sampling}}^2+
\sigma_{\mathrm{geometry}}^2+
\sigma_{\mathrm{ambiguity}}^2
]

其中：

### ADS-B 采样误差

若相邻 ADS-B 点时间间隔为 (\Delta t)，可以先取：

[
\sigma_{\mathrm{sampling}}
\approx \frac{\Delta t}{2}
]

### 几何匹配误差

可利用水平匹配距离和飞机地速估计：

[
\sigma_{\mathrm{geometry}}
\approx
\frac{d_h}{V_g}
]

例如水平距离 25 km、巡航地速约 230 m/s，仅几何误差就对应约 109 秒。

但这只是“沿航迹误差”的近似。如果 25 km 是横向偏离，实际可能是匹配错航线，不能简单换算成时间误差，应直接降低质量或拒绝。

### 航段歧义误差

如果最佳和第二佳候选航段代价很接近，应额外增大不确定度，或者标记为：

```text
match_ambiguous = 1
```

# 进入风场重构前还要做三步

## 1. 风向风速转为 (u,v)

AMDAR 风向一般表示气象学来向：

[
u=-V\sin\theta
]

[
v=-V\cos\theta
]

不要对风向角直接做普通平均。风向跨越 0° 时会出问题，应先转换为 (u,v) 再处理。

## 2. 对同一架飞机的数据去相关或生成 super-observation

一架飞机连续观测的数据高度相关，不能把每一个点都当成完全独立观测。

可以按：

```text
5～10分钟
或 20～50 km 航程
或固定高度层
```

生成超级观测，分别平均 (u,v)、温度等变量，并记录样本数量和离散程度。

具体窗口取决于你的风场网格大小。

## 3. 将时间误差加入观测权重

重建时间误差较大的点应降低权重。例如：

[
R_{\mathrm{effective}}
======================

R_{\mathrm{instrument}}
+
R_{\mathrm{representativeness}}
+
R_{\mathrm{time}}
]

A级点可以正常使用，B级点降低权重，C级点只进入粗时间窗，拒绝点不进入分析。

# 最有效的验证方法：做“伪 AMDAR”实验

因为真实逐点时间不存在，很难直接验证重建时间。但你拥有 ADS-B，可以做闭环实验：

1. 从一条完整 ADS-B 航迹中抽取若干位置、高度点；
2. 隐藏这些点的真实时间；
3. 给它们赋同一个模拟批次时间；
4. 用现在的 AMDAR 时间重建算法恢复时间；
5. 将恢复时间与被隐藏的真实 ADS-B 时间比较。

统计：

```text
时间绝对误差中位数
时间误差90分位
匹配错航段比例
水平投影误差
不同飞行阶段的误差
不同采样间隔下的误差
```

这一步能直接回答：

> 在现有 ADS-B 密度和匹配算法下，重建时间到底能精确到几十秒、几分钟，还是只能精确到半小时。

这比只报告“匹配覆盖率 98.7%”有说服力得多。

## 你当前最应该优先改的三件事

1. **确认并删除“AMDAR 风向—ADS-B 航向”的错误比较。**
2. **从逐点最近匹配改成整条航段的单调序列匹配，并允许低质量数据不匹配。**
3. **用伪 AMDAR 实验验证时间误差，再根据风场网格分辨率制定 A/B/C 质量阈值。**

在当前 25 km 中位水平残差下，数据还不适合直接用于精细风场重构；优化到数公里级，并把不确定度和质量等级带入后续分析后，才比较稳妥。
